# certs/

Generated by `make certs` (WP-02): internal CA, server certificates (APP_HOST, PGADMIN_HOST, db, pgadmin) and DB client
certificates (jira_owner, jira_app, jira_readonly). Never commit anything here except this README (ADR-0010).
For production, replace the APP_HOST and PGADMIN_HOST certificates with publicly trusted ones (deployment requirement D1).
Move the CA private key offline after issuing certificates.
