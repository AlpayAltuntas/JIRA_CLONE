# ADR-0023: Dependency and supply-chain policy

- **Status:** Accepted
- **Date:** 2026-10-17
- **Deciders:** orchestrator
- **Related:** ASVS V15.1.1, V15.1.2, V15.2.1, V15.2.3, V3.7.1; OWASP A03:2025, A08:2025

## Decision
- **Sources:** PyPI and npm registries only; base images from Docker Official Images or the vendor (`dpage/pgadmin4`). Lockfiles (`uv.lock`, `pnpm-lock.yaml`) committed and enforced (`--frozen`), with integrity hashes. Base images pinned by digest. GitHub Actions pinned by full commit SHA.
- **New dependency rule:** justified in the PR/WP report; must be maintained (release in the last 12 months), widely used, and license-compatible. Security-relevant dependencies need an ADR.
- **Inventory:** CycloneDX SBOM generated by Syft for the app image on every CI build and attached as an artifact (V15.1.2).
- **Scanning:** pip-audit, `pnpm audit`, osv-scanner, Trivy (image + filesystem) on every CI run, plus a weekly scheduled run. Dependabot for pip, npm, Docker and Actions.
- **Remediation time frames (V15.1.1)** from public disclosure or fix availability, whichever is later:
  | Severity (CVSS v4.0) | Exploitable in our usage | Deadline |
  |---|---|---|
  | Critical | yes / unknown | 48 hours |
  | High | yes / unknown | 7 days |
  | Medium | yes / unknown | 30 days |
  | Low, or not reachable (documented) | — | next regular update, ≤ 90 days |
  General updates: all dependencies reviewed and updated at least monthly; base images rebuilt at least weekly.
- **CI gate:** fail on any Critical/High with a fix available; Medium fails after its deadline. Exceptions only through an ADR with expiry date.
- **Production image contents:** no dev dependencies, test code, sample data, source maps or build tools (V15.2.3).

## Security impact
Addresses A03 (supply chain) and A08 (integrity).

## Consequences
Weekly maintenance load; Dependabot PRs go through the normal builder → checker flow.
